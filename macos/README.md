# Constellation (macOS native)

Native macOS SwiftUI app scaffold. This directory is self-contained: the app
target lives in `App/`, and all shared logic lives in the local Swift
package `ConstellationKit/`.

## Build & run

The Xcode project itself (`Constellation.xcodeproj`) is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is
not checked in.

```sh
brew install xcodegen
cd macos
xcodegen generate
open Constellation.xcodeproj
```

Then build & run from Xcode as usual (⌘R).

To build from the command line, use the full Xcode toolchain (not the
Command Line Tools) via `DEVELOPER_DIR`:

```sh
env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project Constellation.xcodeproj -scheme Constellation \
  -configuration Debug build
```

(Substitute the path to whichever full Xcode install you have if it's not
at `/Applications/Xcode.app`, e.g. `/Applications/Xcode-beta.app`.)

## Test

The `ConstellationKit` package can be built and tested independently of
Xcode/XcodeGen with SwiftPM:

```sh
swift test --package-path macos/ConstellationKit
```

Tests use the Swift Testing framework (`import Testing`).

> Note: some Command Line Tools releases ship an incomplete Swift Testing
> runtime and `swift test` fails at launch with a dyld "Library not loaded"
> error. If that happens, run the tests through a full Xcode toolchain
> instead:
>
> ```sh
> env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
>   swift test --package-path macos/ConstellationKit
> ```
